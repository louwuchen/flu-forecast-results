**机制与对照。** 先用发行时点可见的周报匹配历史周。某历史周至少有20个地区的成熟目标时，取该周各地区对数人数变化的中位数作为共同变化，从每个地区的变化中减去该数得到当地偏差。共同部分在发行周层面按跨地区增长和日历核拟合，地区部分保留完整局部核。两部分各拟合带固定岭惩罚的局部斜率，将历史供体按当前与历史走势的差异作有界校正，再对各自的加权中位数求和，形成轨迹中心。历史支持不足时回退。中心校正的发行周可靠性、按提前周学习力度、成熟标签限制与原始基础分布沿用上一主版。原版DRF和组合中的既有DRF预测均不作新的调参或处理。

**四轮取舍。** 第一轮直接校正相似供体的局部或跨地区增长差异。共同增长校正在两集改善，只校正当地增长未通过开发。第二轮分解共同与地区变化。仅共同成分在开发改善，但测试退化至0.312343；加回地区偏差后为0.309092。仅用地区偏差未通过开发。第三轮按交错的四周块检验支持是否一致，降低不一致供体的权重获得很小的点估计改善，未替代开发最佳。前三轮共11个候选统一冻结，7个通过者全部测试。第四轮是在看到上述结果后另行冻结的组合实验，5个候选中4个通过开发，全部测试。第四轮中，只校正共同部分为0.333475 / 0.307274，两层都校正为0.333376 / 0.305772，只校正地区部分未过开发筛选。混合备选的测试更低，但主版按通过双阶段后开发WIS排序。首次开发季两个主版的可评分中位数相同，开发点估计改善来自第二个开发季。

**指标边界。** 新主版测试人数WIS为49.9274，上一主版为49.1251，人数尺度上这一项变差。按独立人数开发指标选择的BERNSTEIN_PIT仍然是47.294807 / 50.769392。新主版测试95%覆盖率为93.73%，区间平均宽419.80人，平均绝对误差76.83人。GEO_EQUAL、GLOBAL_QUERY、EPI_LEARN_H、此前测试最低版与原稳定门版本都保留。

**复现。** 16个开发候选，11个冻结通过者全部测试，共27组预测。局部斜率的正规方程与独立增广最小二乘解交叉核对，历史特征按原始发行快照恢复，历史目标满足发布和28天成熟约束。交付包运行 `python src/reproduce_epi_mechanisms.py` 可重建预测、核对数组SHA、八项指标及配对区间。完整分季/期限/种子表与负结果都随包保存。3组初始机制的校正家族为832项，组合轮和最终比较为872项。

**文献定位。** 局部斜率借鉴[Local Linear Forests](https://arxiv.org/abs/1807.11408)在相似度权重上作局部回归的思想。共同与地区偏差的分解与[Stock和Watson的共同因素研究](https://www.nber.org/papers/w6702)相关。本项目直接处理发布有延迟的地区住院轨迹，以周中位数和地区残差构造中心，不是主成分模型，也不将既有局部回归或因子分解本身作为首创。
